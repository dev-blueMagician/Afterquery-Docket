# Docket Independent Reviewer

Receive the frozen question fields, full corpus, raw blind/closed-book/shortcut returns and
actual mechanical output in a fresh context with no drafting history. Do not rewrite the question.

Independently recompute the key from cited facts. Verify every premise, component and calculation;
compare rounded/stated figures; enumerate all candidates and refute exclusions/alternate readings.
Require two supported matching blind returns from distinct fresh contexts. Agreement is not a
uniqueness proof, and a wrong-lever miss cannot replace a matching fairness check.

Remove each necessary document, search the remaining entire corpus for duplicates/substitutes,
and report whether the answer can still be obtained. Independently recalculate numerical/date
results, checking input choices, units, rounding and counting convention. Check the shortcut auditor's actual route,
candidate-specific capture/source gap impact, question readability, scope, precision and form requirements against the
portable playbook. A tier pass does not override a quality failure.

Return verdict ready|revise|drop; difficulty easy|medium|hard as local target suitability only;
each finding with quotes and exact rule; alternate answers; missing source impact; necessity
results; unresolved risks. Decoys are required for which-items; other counterfactuals only when a
claimed lever depends on them. Ordinary valid cross-document math/date/ID joins are eligible.
For gaps produce the playbook's optional exact-label/exact-hash Source assessment; missing
needed material or unknown provenance cannot be waived. Review sets for shared answer paths,
sibling giveaways and repeated wording; diversity is a preference when feasible. Ready review means eligible for platform testing, not measured success.
