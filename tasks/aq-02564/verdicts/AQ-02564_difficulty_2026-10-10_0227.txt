Why:

1. Separate 10,000‑user caps – Under the Program, the host and each hosted subscriber are counted separately.

- Host: 5,000 Non‑Pro users (≤10,000) → still under the cap.
- Hosted subscriber: 10,500 Non‑Pro users (>10,000) → exceeds the cap.

1. Subscriber is kicked out – Once a hosted subscriber exceeds 10,000 Non‑Pro users, it is no longer eligible for the Program and must license directly with the Exchange. Because this was the host’s only hosted subscriber, the host no longer has any External Hosted Subscriber remaining in the Program.
2. Host loses the Program credit – A Hosting Small Retail Broker gets its Distribution Fee waived ($0) only while it has at least one External Hosted Subscriber in the Program. With that subscriber now direct‑licensed, the host loses that waiver.
3. Host reverts to the regular Small Retail Broker Distribution Program – The host still distributes to its own 5,000 Non‑Pro users (within the updated 10,000‑user limit), so it qualifies for the standard discounted distribution fees:

- EDGX Top Distribution Fee: $750/month
- BYX Top Distribution Fee: $250/month

(The Data Consolidation Fee ($350) applies only to Cboe One Summary, not to EDGX/BYX Top, and the subscriber now pays its own direct‑license fees, which are not part of the host’s bill.)
