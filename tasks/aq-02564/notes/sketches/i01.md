## Question

At 10,000 non-professional users, how much lower would a hosted subscriber's total monthly EDGX Top and BYX Top feed fees be under the hosted programs than under the existing small-retail-broker programs?

## Answer

$1,400

## Evidence

- D05 (existing program, L48): "This program provides a discounted Distribution Fee of $750/month for EDGX Top Data Feed"
- D05 (existing structure, L62): "These fees are in addition to the standard Professional and Non-Professional User fees."
- D05 (hosted program, L74): "the External Hosted Subscriber shall also receive a waiver of the Distribution Fee (a credit of $750/month for EDGX Top Data Feed"
- D05 (hosted program, L74): "it shall be a set monthly fee of $750 for EDGX Top"
- D05 (footnote 12, L77): "10,000 Users x 0.10/Non-Professional User = $1,000"
- D05 (cap raised, L81): "increase the number of Non- Professional Data User maximum from 5,000 to 10,000"
- D06 (existing program, L50): "This program provides a discounted Distribution Fee of $250/month for BYX Top Data Feed"
- D06 (hosted program, L75): "the External Hosted Subscriber shall also receive a waiver of the Distribution Fee (a credit of $250/month for BYX Top Data Feed"
- D06 (hosted program, L75): "it shall be a set monthly fee of $100 for BYX Top"
- D06 (footnote 12, L79): "10,000 Users x 0.025/Non-Professional User = $250"

## Sketch notes

Hook/mechanism: h1. Two parallel notices of one Cboe program; only the Top-feed figures differ (D05 EDGX
$750 / $750 / 0.10, D06 BYX $250 / $100 / 0.025). Existing program: discounted Distribution Fee plus the
standard per-user fees (D05 L62, D06 L61). Hosted program: the hosted subscriber's Distribution Fee is
waived and a set monthly fee replaces the Non-Professional User fees (D05 L74, D06 L75); Professional
User fees "shall remain the same", so they cancel in the difference. Footnote 12 of each notice prints a
"maximum, savings" ($250 EDGX, $150 BYX) computed at exactly 10,000 users that compares only the user
fees with the set fee: the waived Distribution Fee is not in it.

Ambiguity:
- $400 (fn 12's $250 + $150) -> fails "total ... fees": fn 12 counts user fees only, while the existing
  programs also charge the Distribution Fee (D05 L48, D06 L50) that the hosted programs waive (D05 L74,
  D06 L75).
- $1,000 or $400 (one exchange only) -> fails "EDGX Top and BYX Top".
- Cboe One Summary added (+$5,500) -> fails "EDGX Top and BYX Top" (Cboe One is a separate feed, D05 L47).
- Host's credit added (+$1,000) -> fails "a hosted subscriber's" fees.
- Old 5,000-user cap: the same filings raise the existing programs' cap to 10,000 (D05 L81, D06 L83),
  effective on filing (D05 L225, D06 L213), and the hosted programs cap at 10,000 ("no more than", D05
  L74, D06 L75); under a 5,000 reading the subscriber would get no existing discount at all and the
  bundle prints no undiscounted Distribution Fee, so that reading has no answer. fn 12 itself compares at
  10,000 users.
- Professional users: unchanged fees cancel ("shall remain the same", D05 L74, D06 L75).

Necessity:
- D05: only source of EDGX's $750 Distribution Fee, $750 set fee and 0.10 per-user rate. D06 names EDGX
  only as an affiliate (L48); no other document mentions Cboe. Without D05: BYX side $400 only, or $800
  if BYX's figures are assumed for EDGX.
- D06: only source of BYX's $250, $100 and 0.025. D05 names BYX only as an affiliate (L46). Without D06:
  $1,000, or $2,000 if EDGX's figures are assumed for BYX.

After clarification: "EDGX Top and BYX Top" and "total" pin scope and measure without supplying any
figure; both documents remain indispensable.

Selected lever(s) and applicable tests: Calculate across documents; Who belongs where (EDGX vs BYX
figures in look-alike paragraphs); look-alike measure (fn 12). Wrong routes: fn 12 sum 400; EDGX figures
for both 2,000; BYX for both 800; EDGX waiver missed 650; BYX waiver missed 1,150; NYSE $0.20 rate
(D05 L100) 4,150; Cboe One added 6,900; Distribution Fees only 1,000. None equals 1,400.

Source risks: "too vague" block if both form solvers take fn 12's $400 (fallback pin: "Distribution Fees
included"); the 5,000-cap reading (above).

Author calculation: EDGX existing 750 + 10,000 x 0.10 = 1,750, hosted 750, lower by 1,000. BYX existing
250 + 10,000 x 0.025 = 500, hosted 100, lower by 400. Total 1,400 dollars a month, exact.
