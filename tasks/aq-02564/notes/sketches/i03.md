## Question

A hosting broker with 2,000 non-professional users has one hosted subscriber, which grows to 10,500 non-professional users. What is the host's monthly bill for EDGX Top and BYX Top data after that?

## Answer

$1,250

## Evidence

- D05 (hosted program, L73): "that it is normally responsible for under the existing Small Retail Broker Program"
- D05 (over the cap, L74): "shall no longer be eligible for the program and will be required to directly license with the Exchange for the Applicable Feed"
- D05 (host eligibility, L74): "so long as it has at least one External Hosted Subscriber"
- D05 (existing program, L48): "This program provides a discounted Distribution Fee of $750/month for EDGX Top Data Feed"
- D05 (footnote 12, L77): "10,000 Users x 0.10/Non-Professional User = $1,000"
- D06 (existing program, L50): "This program provides a discounted Distribution Fee of $250/month for BYX Top Data Feed"
- D06 (over the cap, L75): "shall no longer be eligible for the program and will be required to directly license with the Exchange for the Applicable Feed"
- D06 (host eligibility, L76): "so long as it has at least one External Hosted Subscriber"
- D06 (footnote 12, L79): "10,000 Users x 0.025/Non-Professional User = $250"

## Sketch notes

Hook/mechanism: h13 (round 2). A subscriber that exceeds the 10,000 cap leaves the program and licenses directly
(D05 L74, D06 L75), so it is off the host's bill. The host stays eligible only "so long as it has at least one
External Hosted Subscriber", and the notices' own example keeps a host in only because "the other" subscriber
remains (D05 L74, D06 L76): with its only subscriber gone, the host loses the credit and pays the Distribution Fee
"it is normally responsible for under the existing Small Retail Broker Program" (D05 L73, D06 L75), $750 + $250,
plus its own users at the footnote-12 rates.

Ambiguity: credit kept ($250 or $1,100) needs the over-cap firm to count as the host's subscriber, which the example's
"the other External Hosted Subscriber may still continue" rules out; professional users none; "after that" = a month
with the subscriber over the cap.

Necessity: D05 only source of EDGX's $750 and 0.10; D06 only source of BYX's $250 and 0.025 (as h1).

Selected lever(s) and applicable tests: Calculate across documents; conditional (eligibility lost). Wrong routes
(scratch calc_i03.py): credit kept, subscriber dropped 250; credit kept, subscriber's set fees still billed 1,100;
credit lost, set fees still billed 2,100; EDGX figures for both 1,900; BYX figures for both 600; Distribution Fees
only 1,000. None equals 1,250.

Source risks: the eligibility rule names its own condition in the same paragraph as the cap rule (the aq-02483
lesson: a rule that names its missing input is no trap), so a quick-test "too easy" is the likely result; sibling of
the dropped h1/h2 (same fee inputs).

Author calculation: 750 + 2,000 x 0.10 + 250 + 2,000 x 0.025 = 750 + 200 + 250 + 50 = 1,250 dollars a month.
