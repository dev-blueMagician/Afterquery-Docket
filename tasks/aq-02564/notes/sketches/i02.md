## Question

A hosting broker with 5,000 non-professional users of its own serves one hosted subscriber with 6,000. Under the hosted programs, what is its total monthly bill for EDGX Top and BYX Top data?

## Answer

$1,475

## Evidence

- D05 (hosted program, L73): "would be eligible for a credit of its Distribution Fee (a credit of $750/month for EDGX Top Data Feed"
- D05 (host pays, L70): "ultimately the Hosting Small Retail Broker Distributor is responsible for payment of all data fees"
- D05 (per-firm count, L74): "looked at on a firm level"
- D05 (hosted program, L74): "it shall be a set monthly fee of $750 for EDGX Top"
- D05 (footnote 12, L77): "10,000 Users x 0.10/Non-Professional User = $1,000"
- D06 (hosted program, L75): "would be eligible for a credit of its Distribution Fee (a credit of $250/month for BYX Top Data Feed"
- D06 (hosted program, L75): "it shall be a set monthly fee of $100 for BYX Top"
- D06 (footnote 12, L79): "10,000 Users x 0.025/Non-Professional User = $250"

## Sketch notes

Hook/mechanism: h2. The host is billed for itself and its hosted subscriber (D05 L70, D06 L73); its own
Distribution Fee is credited while it has one hosted subscriber (D05 L73, D06 L75); its own users pay the
standard per-user fees (no set fee for hosts); the subscriber pays the set fees; the 10,000 cap is
counted per firm (D05 L74, D06 L75), so 5,000 + 6,000 = 11,000 does not disqualify anyone.

Ambiguity: the host's own users are priced only through fn 12's rates (the user fees the set fee
replaces); professional users none (all non-professional); "its total monthly bill" = host's bill,
which includes the subscriber's fees.

Necessity: as i01 (D05 EDGX figures only; D06 BYX figures only).

Selected lever(s) and applicable tests: Calculate across documents; firm-level count. Wrong routes:
combined 11,000 users read as ineligible -> host's existing fees 1,625; host credit missed 2,475;
subscriber at per-user rates 1,375; host at set fees 1,700; subscriber's fees left off 625. None equals
1,475.

Source risks: shares i01's inputs (sibling); the per-user rate for the host's own users is inferred from
fn 12, a weaker premise than i01's.

Author calculation: host own 5,000 x 0.10 = 500 and 5,000 x 0.025 = 125; subscriber set fees 750 + 100 =
850; host credits 0; total 500 + 125 + 850 = 1,475 dollars a month.
