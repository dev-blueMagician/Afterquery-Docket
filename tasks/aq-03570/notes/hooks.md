Design consequence, as first written (2026-10-12, before Run 1): the miss that recurs in this family is trust
in a commenter's own account, so the hook must make that account, and the set of letters the commenter wrote
itself, both give a wrong but complete-looking answer. Run 1 did not bear that out for the easier solver here:
it ignored the own account and counted the documents in hand. Corrected consequence: the letter that is not a
document is what holds the easier solver, and the middle solver needs a gate the question does not point at,
so the set is named by what makes a letter belong to it ("signed") and no clause tells the solver what to count.
