Written once by `bundle-mapper` from `text/` (and `docs/` for flattened tables and scans).
It is for navigation, like the form's bundle overview: where things are, not what to ask.
Questions quote the documents, never this map.

Line numbers are `text/Dnn.txt` lines (L = line). `docs/` originals carry the same text two
lines earlier (text L = docs L + 2, because `text/` adds a "# Dnn | source" header and a blank
line). Quoted fragments keep the source's spacing and its `?`/`*` substitutions for apostrophes
and dashes. Arithmetic marked "check" was done by hand for navigation; it is not printed unless
quoted.
