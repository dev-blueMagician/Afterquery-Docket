## Question

Of the privately insured credit unions in the state whose bank regulator adds a $100 charge per branch office to its assessment, what percentage had a Web site that GAO's 2003 review found lacking the required notice that it had no federal deposit insurance? One decimal.

## Answer

25.0%

## Components

- c1: 25.0%

## Reasoning

1. Doc 5: among the state bank regulators GAO describes, only the Idaho Department of Finance has an assessment structure that "includes a graduated base fee and excess fee based on total assets and $100 per branch office", so the state is Idaho.
2. Doc 2: Table 3 lists, for each state, the total number of privately insured credit unions, the number of Web sites identified and analyzed, and the number and percent of those Web sites without the required disclosures. GAO looked for Web sites of all 212 privately insured credit unions and found 78. Idaho's row shows 20 privately insured credit unions, 7 Web sites analyzed and 5 Web sites without the disclosures.
3. Doc 2 and Doc 5: 5 / 20 = 25.0% (to one decimal place) of Idaho's privately insured credit unions.
4. Wrong route: the table's printed percentage is the share of Idaho's analyzed Web sites, not of its privately insured credit unions, so it answers a different question.
