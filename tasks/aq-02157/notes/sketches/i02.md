## Question

What percentage of youth-vaping consultation respondents picked the Netherlands' method of restricting vape flavours but not Finland's, to one decimal place?

## Answer

6.1%

## Evidence

- D02 (L326, Option 2): "In the Netherlands, for example, there is a specified list of ingredients that can be used in vapes"
- D02 (L330, Option 3): "Finland, for example, has restricted all characterising flavours for vapes, apart from the flavour of tobacco."
- D01 (L554, Table 4): "Option 1, Option 2|2.6%"
- D01 (L561, Table 4): "Option 2: limiting the ingredients in vapes only|3.4%"

## Sketch notes

Hook/mechanism: h2. Doc 1 names each restriction method by a country example (Netherlands = Option 2,
ingredients; Finland = Option 3, characterising flavours); Doc 2's Table 4 gives every selected
combination as a share of respondents. Match (contains Option 2) then exclude (contains Option 3).
Ambiguity: "only" row 3.4 -> fails "picked ... method" (combinations count); any Option 2 33.2 -> fails
"but not Finland's"; Option 2 with Option 3 27.1 -> fails the exclusion; reversed mapping (Option 3 not 2)
15.9 -> contradicts Doc 1 L326/L330; Table 17 individuals (UK column, "not all option combinations are
shown") -> fails "respondents" and cannot give the combinations; dropping the two "Don't know" rows 6.0 ->
those respondents still picked Option 2. Flavour-set question A/B/C is a different question (which
flavours, not how); both countries map to tobacco-only there, so "Netherlands but not Finland" has no
reading on it.
Necessity: Doc 1 -> country-to-method mapping (L320-330); Doc 2 L473 lumps "Denmark, Finland, the
Netherlands" as having "prohibited certain flavours", pointing a reader without Doc 1 to the flavour
lists or Option 3; Docs 3-5 none. Recall risk: the Dutch ingredient list and Finland's characterising-flavour
ban may be known from outside (probe). Doc 2 -> Table 4 combination shares (L549-567), the only source of
respondent combinations (Table 17 shows singles and all three only).
After clarification: wording names countries, not options; Doc 1 remains needed.
Selected lever(s) and applicable tests: Match then exclude (exclusion changes 33.2 to 6.1); Scatter the
pieces. Universe: 15 rows of Table 4, total 100.0; included rows 1+2 (2.6), 1+2+DK (0.0), 2 only (3.4),
2+DK (0.1); excluded Option 2 rows 1+2+3 (23.1), 1+2+3+DK (0.1), 2+3 (3.9), 2+3+DK (0.0).
Source risks: rows are rounded to 0.1 (true value 5.9-6.3); gold is the sum of the printed shares.
Author calculation: 2.6 + 0.0 + 3.4 + 0.1 = 6.1 (Decimal, scratchpad aq02157_calc.py).
