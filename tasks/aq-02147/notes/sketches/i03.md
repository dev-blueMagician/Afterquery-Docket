## Question

At the median saving per retained employee, how many retentions a year would offset an 80% rate's rise over current SSP costs?

## Answer

52,500 employees

## Evidence

- D02 (Doc 2 L859, Annex A Table 3): "|Total|£4,700|£8,000|£11,000|"
- D05 (Doc 3 L171, Table 2): "|Total costs|£0.65 billion|£1.04 billion|£1.06 billion|£1.07 billion|"

## Sketch notes

Hook/mechanism: h9, replacing the retired h1 after q01's Run 1 (Doc 3 replaceable by Doc 4). The 2024
consultation prices an 80% rate at £1.07bn a year against £0.65bn for the current system (Doc 3 Table 2 only;
Doc 5 prints the £1.07bn but no current cost). It also argues the reform helps retention, citing Oxford
Economics' average £30,614 cost of losing an employee (Doc 3 para 18). The only median estimate of what
employers save per retained employee is the 2021 response's annex (Doc 2 Table 3, total £8,000; prose
"between £5,000 and £11,000"). 0.42bn / £8,000 = 52,500 retentions a year.

Ambiguity: Doc 3's £30,614 is an average and a cost of loss, not a median saving -> 13,719 -> fails "median".
Table 2's replacement-cost median £5,000 and Table 1's productivity median £3,100 are components of the total
saving (prose: "could save employers between £5,000 and £11,000 ... for each employee") -> 84,000 / 135,484.
Table 4's £4,100 is an individual's health benefit -> 102,439. The 80% total £1.07bn -> 133,750 and Doc 5's
60-versus-80 gap (£30m) -> 3,750 both fail "rise over current SSP costs". Summing the rounded components
(£8,100) -> 51,852; the printed Total is the direct figure. Searched all five documents for "median", "save
employers", "per employee", "retain".

Necessity: D02 (Doc 2): the only median retention saving; without it the nearest substitute is Doc 3's
£30,614 (13,719). D05 (Doc 3): the only current-system cost (£0.65bn); Doc 5 has £1.07bn and £1.04bn but no
current figure, Doc 1's £1.5bn is a 2019 estimate (it would give a fall). The question states 80%, so the
response (Doc 5) is not needed for the rate.

After clarification: the question gives none of £8,000, £0.65bn or £1.07bn.

Selected lever(s) and applicable tests: Scatter the pieces; Calculate across documents (Picking the right
measure: median total saving vs Doc 3's average loss and the component medians; rise vs total cost).

Source risks: the two estimates come from different years (2021 annex on 2014 study data; 2024 DWP model); the
question makes the assumption explicit ("at the median saving"). Doc 3 para 18 and Doc 5 L118 tie the SSP
reform's employer cost to retention and productivity gains.

Author calculation: 1.07 - 0.65 = 0.42 (billion pounds); 0.42 bn / 8,000 = 52,500 (Decimal; float 0.42/8 =
0.0525 million).
