## Question

How many more entries did the loading matrix of the brain spatial-factor study's tissue-section model have than the loading matrix of the autoimmune subtype study's selected model?

## Answer

17,312 entries

## Evidence

- D05 (Sec. 1.1, text line 29): "the columns index spatial locations"

## Sketch notes

Hook/mechanism: both transcriptomic papers fit factor models but orient them differently. The
brain paper places the spatial dimension in the loadings (W, U are m x k; m = spots, 3,592, U kept
at all locations including the 400 held out; k = 7), so 3,592 x 7 = 25,144. The autoimmune
loadings are genes x factors (B is p x q; p = 979, q = 8), so 7,832. 25,144 - 7,832 = 17,312.
Selected lever(s) and applicable tests: entity resolution (what "loadings" index in each paper);
unit normalization (matrix dimensions); calculate across documents. Decoys: genes as the loading
rows (14,638 x 7) gives 94,634; training spots only (3,192 x 7) gives 14,512; Remark 2's effective
loading count p + Gq = 1,131 gives 24,013; p = 3000 gives 1,144; simulation k = 3 gives 2,944.
Source risks: "entries" must not be read as free parameters (orthogonality, B = SMH); the question
asks for matrix entries. All three brain analyses share m and k, so the analysis choice is moot.
Overview of Doc 5 prints "k components · m spatial locations · n observations".
Author calculation check and counting convention: python 3592*7=25144, 979*8=7832, difference 17312.
