When a Docket hook is a set with one hard-to-find member (a witness, party or item whose membership only a passage in a second document shows), check two things before I sketch it as a list: do the members carry a count or an amount, and does one document print a figure for the visible members that looks complete on its own? If both hold, the first sketch is the total, and the list form goes to the quick test only beside it.
