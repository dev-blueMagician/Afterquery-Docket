When I check a Docket question's wording (my draft or the user's rewording), I must not report a second reading as removed because my intended parse no longer sees it. Take each noun phrase at its nearest literal reading, above all a source phrase that names a party with figures of its own ("X's store counts", "the number of stores X provides", "the figure X states"). If the reading is possible, say it is still there, name the words elsewhere in the sentence that reject it, and say the form's Checks and the difficulty run will show whether solvers take it.

**Why:** user, 2026-10-12, after submitting aq-03557 q01 at Medium: "plz check arrived verdicts by using your feedback skill and upgrade your ability". The user had reworded the question twice. I flagged "Woolworths' store counts" as readable as Woolworths' own stores, then told the user that "With the number of stores Woolworths provides" "can no longer be read as Woolworths' own stores" and logged "No second reading found". In the difficulty run on that wording, three attempts (one low, two medium) took exactly that reading and answered 71 instead of 376, and the strongest solver weighed it four times before rejecting it. The run still landed in band, but two of the medium solver's four misses came from the sentence, not the documents, which a reviewer could call loose wording. The same thing had already happened on aq-02028 q02 ("the throughput ... terminal states"). My interpretation, not the user's words: "upgrade your ability" here means each verdict read-out should change how I vet the next wording, as with [[docket-repair-must-not-add-solved-family]].

It also happened on my own first wording, not only on a user's rewording: aq-03570 q01 rev 1, 2026-10-12. Before handing over "comment letters that the Sierra Club signed" I had weighed the reading "letters whose signature the documents show", judged it safe, wrote "no second reading in these documents" in the question file and said nothing of it to the user. In the run, five attempts took that reading, including all three of the strongest solver's, and the gate failed ("Answer not supported"). The user's request both times was the same one line ("plz check arrived verdicts by using your feedback skill and fix").

Third case, a qualifier in my own sentence that some gold members fail (aq-04807 q02 rev 0, 2026-10-14). User, with the Checks screenshots: "two checks failed. You even run into such a mistake. Idiot." The question asked for areas EPA said need no contingency measures "because of an approved international-emissions demonstration"; two of the three members' demonstrations were only proposed for approval ("if the Agency finalizes approval"). My readings note listed that reading and wrote it off as "rejected by 'has EPA said'", and my hand-over to the user left it out. "One defensible answer" failed before any run: the form's solvers answered "Imperial County" (the one approved case) and "none". Mine, not the user's words: a reading that a word in the question itself selects is not rejected by some other phrase; that word is the defect, and it comes out before the hand-over.

**How to apply:** in the reply that vets a wording, give one line per phrase that can be read another way: the other reading, the answer it would give, and the words that rule it out. Record the same in the question file's readings note instead of "no second reading found". Before any hand-over, test every qualifier in the question (approved, final, current, adopted, in force) against each gold member's status in the documents; if one member fails a qualifier, drop or change the qualifier, never argue it away.
