# Command case law (frozen 2026-10-14)

Moved verbatim from .claude/commands when the objective became Hard-only. Measured against the Low and
Medium solvers; history, not current rules. The current rules are in
[hard-playbook.md](../reference/hard-playbook.md).

## docket-new.md step 5

   In a bundle of several parties' documents, list first every outside organisation that two or
   more documents quote with figures and compare the periods quoted: a first half in one document
   and a full year in another leaves a remainder no document prints (aq-03120, Medium).
   Before a sketch goes anywhere, search the bundle for each phrase that names the asked period or
   population. If a document uses it as a label for a different or narrower item ("half-year
   results"), name the period by its structure instead, and never date a period by an event whose
   name carries another period's label (WORKFLOW section 4).
   For a posed case run through stated rules, list its steps before any write-up and mark each one a word
   in the question points at (a figure, a date, a status). Count only the unpointed steps: with one, the
   design measured Easy at Low 1/5 (aq-03736 q01), every pointed step cleared by all five attempts. A
   second unpointed step must sit in a different passage (WORKFLOW section 6, repair order 6).
   When a hook is a set with one member that only a second document shows, check before sketching the list
   whether the members carry counts or amounts and whether one document prints a complete-looking figure for
   the visible ones. If so sketch the total first and quick-test the list only beside it (aq-03993 q02: list
   Medium 4/7, "Between levels"; total Medium 2/6, in band). A list result on a sibling bundle is no reason
   to skip the check (WORKFLOW section 3).
   Never record that a text is silent on an item before searching its recitals and footnotes with a pattern
   that can match at the start of a paragraph (WORKFLOW section 2).
   Before any sketch is offered, run delete-and-guess on each ticked document and write the result in the
   sketch: with that document gone, what does a solver answer from the rest and from what it knows of a
   well-reported law? If the guess is the gold, the document is not needed (aq-03736 q02: a run spent on
   "Your answer can still be reached without document 3"). Redo it after every narrowing of the ask
   (WORKFLOW section 4). The step audit above does not replace it.

## docket-new.md step 6 (opening)

6. Cheap-screen sketches with /docket-check before full reasoning/components write-up.
   When the task page shows quick tests left (they need only a question and a short answer), the
   first hand-over is the table of screened sketches and nothing else: no question file, prepare
   or full form until the user reports a survivor (aq-03950: a full write-up made first failed
   its quick test). Set difficulty_target to the lowest tier the user named as open, not to the
   tier a recipe measured on another bundle; the field is inside the fingerprint.

## docket-feedback.md step 6

   Before choosing a repair, read every wrong attempt's own Full answer and Reasoning, and the
   strongest solver's every-document attempts, and write down for each what it cleared as well
   as where it left the gold. When the gate or "One defensible answer" fails on a derived gold
   and the strongest solver took the same reading as the weaker misses, the wording is open:
   replace the open term with a one-reading, structural description and change nothing else.
   Never repair by adding a cue to calculate (a percentage form, "on reported figures", "stated
   or implied"): each was quick-test too easy on aq-03120, where the one-reading wording with no
   cue then measured Medium (WORKFLOW section 6, repair order).
   Run `tools/verdict_summary.py <capture> --q <question.md>` and use its "evidence echoed" lines to
   tell an attempt that never reached the deciding clause from one that read it and set it aside
   (aq-03736 q01: the page called four misses "the wrong application phase"; all four had the right
   phase and none had reached the sentence's closing exception). When a result is one tier low on a
   posed case, list which steps every low attempt cleared and count the steps no word in the question
   points at; do not add a step inside the passage that held, and if no second unpointed step exists in
   a different passage, say so and move to another hook (WORKFLOW section 6, repair order 6).
   On "Between levels", read which two solvers the verdict names and repair toward the tier that is open,
   not toward the page's "Make it harder" heading. With Medium open and "Too hard for the medium model but
   too easy for the high model", restate the membership test in the documents' own kind of term, add no
   clause, and send the changed sentence back as a sketch for a quick test (aq-03707 q03: Medium 1/7 · High
   3/3, then Medium 2/6 in band; WORKFLOW section 6, repair order 7).
   Report the measured result and the next action only. Do not attach odds or a "likelier" tier,
   and do not recommend releasing a bundle while a one-reading, no-cue wording of a hook whose
   counts were in band is untested.
