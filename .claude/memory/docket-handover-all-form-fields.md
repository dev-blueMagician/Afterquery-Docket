User instruction (2026-10-07, after the form added required "Targeted failure modes"): "from now you
should also prepare it with Question and Gold Answer, Step-by-step reasoning, Answer components,
evidence, Necessary documents, Reasoning tags."

Every hand-over to the user is the complete form, in the form's order:
- Question
- Number of asks
- Gold answer
- Step-by-step reasoning
- Answer components
- Evidence (document Doc N, the component it proves, the quote)
- Necessary documents (role; "or" alternatives; which to leave unticked)
- Reasoning tags (tick / leave unticked)
- Targeted failure modes (1-3: trap, cause, three boxes, 150+ words)

**Why:**
- The form now blocks Submit without failure modes.
- Partial hand-overs have gone wrong. On aq-01333 q01, step text was pasted into an evidence row, and the
  platform reviewer asked for whole fields.
- After rev 4, the saved form of aq-01278 q02 still held 8 evidence rows that differed from rev 4's 10,
  and 2 of its 4 tags. The cause is not known.

**How to apply:**
- Fill `## Targeted failure modes` (and `## Necessary documents` when a role is not Answer component)
  in the question file.
- Run `python tools/check_questions.py tasks/<slug> --handover --q qNN` and give the user
  notes/handover-qNN.md, or its fields, whole.
- Name what in the form each block replaces, and say whether the platform needs a new difficulty run.
  Its run history names question, answer and necessary-document edits; others are not named. Ask the
  user to confirm on the difficulty panel after pasting. The aq-01278 page, 2026-10-07, showed "passes on
  the current content" beside "This result is for an earlier version of your question.", so that result
  is recorded as unknown.
