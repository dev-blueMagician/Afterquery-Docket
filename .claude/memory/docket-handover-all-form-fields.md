## Words a rewording must keep (2026-10-09)

The form's "Question in your own words" and "Reasoning in your own words" checks lead the user to
paraphrase hand-overs before pasting. A paraphrase can change the referent. aq-02157 q04: "...to the
smokefree consultation response" became "...to the smoke free consultation"; the difficulty run (Run 1,
Too hard, 0/15) then measured a question whose literal answer was the edition decoy (13.1%, Doc 1's
£7.87), and the platform called it "too vague". The run counts once per version, so the slip cost a run.
aq-02360 q02 (2026-10-09): the run measured "In how many days since the opening of the 2023 remedy
consultation was the last day for submitting opted-out elections?" for the hand-over's "How many days after ... opened was
its proposed last day for receiving opted-out service elections, barring extensions?"; the Coach's main complaint targeted the
paraphrase's "since the opening", and the result could not be bound to the prepared revision.
So with every hand-over, list the load-bearing words in one line under the Question block: the edition,
period or entity identifiers that separate gold from decoy ("government's response", "calendar year"),
the precision, and the answer's unit word ("percentage points"). Prefer referents that survive a
paraphrase ("the government's response to the smokefree consultation" over "the smokefree consultation
response"). For reasoning, say which numbers and unit words must stay byte-identical (see
[[docket-form-automated-checks]]).

The asked quantity is load-bearing too. q04 Run 2 (2026-10-09): I had listed the referent, "minimum", "20-pack" and
the precision but not "By what percentage"; the user's paraphrase asked "What is the increase in ..." while the gold
stayed 21.6%, and the run (Too hard, 0/15) graded correct pound answers wrong: the High model gave the literal
£1.5 five times. Start the list with the asked quantity and its unit. When a paraphrase is natural, fair and
its traces show the intended route, consider adopting the tested wording verbatim and aligning the gold
(q04 rev 3, origin user+claude): the record then binds to the platform's question, and the user does not
have to paraphrase again.

## Failure modes after a difficulty run (2026-10-10)

Failure modes are declared before any solver has tried the question, and the prediction is often wrong.
aq-02564 q02 rev 1 passed at Medium with two declared modes: one (the BYX credit kept, $2,125) caught two of
ten attempts, the other (the second subscriber dropped from both programs, $1,625) caught none, and the
commonest wrong route (the hosted subscribers' set fees left off the host's bill, $875, three low attempts)
was not declared. The user had already submitted when the capture arrived, so the modes went in as predicted.
Failure modes are not among the edits that need a new result, so with every hand-over that precedes a
difficulty run, add one line: if the run passes, send the capture before Submit and the modes can be aligned
with the observed wrong answers at no cost of a run. Do it only when the user wants it; a pass can be
submitted as it stands. aq-03557 q01 (2026-10-12): the line went into the first hand-over only. Two
shorter hand-overs followed as the user reworded the question, neither repeated it, and the user submitted before
the capture arrived; declared mode 2 (a wrong-kind decoy, 392) had caught no attempt. Put the line in the last
message before the run, every time, however short that message is. Record the observed routes in the question's Feedback log either way, and in
notes/feedback-qNN.md once frozen. See [[docket-local-solver-calibration]] (trace rule).

## Checking a rewording: report readings, do not clear them (2026-10-12)

aq-03557 q01. The user's first rewording said "Woolworths’ store counts"; I flagged that it could mean Woolworths'
own stores (71). The next said "With the number of stores Woolworths provides"; I told the user it "can no longer
be read as Woolworths' own stores" and logged "No second reading found". In the difficulty run on that wording
three attempts (one low, two medium) took exactly that reading and answered 71, and the strongest solver weighed
it four times before rejecting it from "any retailer's submission" and from the rivals' counts Woolworths gives.
The run still landed at Medium, but two of the medium solver's four misses came from the sentence, not the
documents. When checking a wording, take each noun phrase at its nearest literal reading, above all a source
phrase naming a party that has figures of its own ("X's counts", "the number X provides", "the figure X states",
as on aq-02028 q02). If a reading is possible, say it is still there, name the words elsewhere in the sentence
that reject it, and say that the form's Checks and the run will show whether solvers take it. Never report a
reading as removed on the strength of the intended parse.
